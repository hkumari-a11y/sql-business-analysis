# Retail Sales KPI Analysis (SQL Portfolio Exercise)

**Status:** New illustrative portfolio project built with synthetic data. Not a claim of past employment or client results.

## Business question
How can an analyst measure monthly revenue, order volume, average order value, and returning-customer behavior from transactional records?

## Deliverables
- [Sample schema and data](schema_and_sample_data.sql)
- [Business KPI queries](analysis.sql)

## Questions answered
1. How much revenue and how many orders did the store record by month?
2. What is the average order value?
3. Which customers made repeat purchases?
4. Which products generated the most revenue?

## How to run
Execute the schema file, then the analysis file in PostgreSQL. All records are fictional. The example is designed to be understandable and reproducible.

## Skills demonstrated
SQL joins, common table expressions, date truncation, aggregation, distinct counts, filtering, and business KPI definitions.
