# SQL Business Analysis

## Overview
SQL portfolio work completed during my M.S. in Business Analytics at Santa Clara University. The repository demonstrates the use of SQL to answer business questions, summarize data, calculate KPIs, and support reporting.

## SQL Skills
- JOINs
- GROUP BY and HAVING
- Aggregate Functions
- Subqueries
- Views
- Business Reporting
- KPI Calculations
- Trend Analysis

## Business Analysis Focus
SQL is used here as a business analysis tool to organize data, answer operational questions, identify patterns, and produce decision-ready summaries.

## Project Themes
- Customer and sales analysis
- KPI calculations
- Business reporting
- Trend analysis
